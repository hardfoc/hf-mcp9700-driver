◆ kDefaultRangeMarginCelsius

constexpr float hf::mcp9700::kDefaultRangeMarginCelsius = 8.0F
inlineconstexpr

Default plausibility margin (°C) added on both sides of the specified range.

Covers the worst-case sensor accuracy of the MCP9700 (-4 °C / +6 °C, DC Electrical Characteristics) plus a little ADC error. With the default coefficients a reading is accepted from -48 °C (20 mV) to +133 °C (1.83 V); an open or grounded input (0 V, -50 °C) is rejected.

Default lower end of the specified temperature range (°C).

MCP9700/9700A/9700B: -40 °C to +125 °C (DS20001942, Temperature Characteristics). Over that range VOUT is 100 mV to 1.75 V (Section 3.2).
